## 2. 처리하는 정보

### 기기 안에서 처리

- 설치된 앱의 이름과 패키지 식별자
- 앱별 사용 시간과 화면 켜짐 상태
- 현재 실행 중인 앱
- 사용자가 설정한 시간 제한, 차단 정책, 고행 단계와 임시 허용 상태
- 관리 PIN의 솔트가 포함된 단방향 해시

화면이 꺼진 시간은 사용 시간에 포함하지 않도록 처리합니다. PIN 원문은 저장하지 않습니다.

### 부모·자녀 연결 시 Firebase로 전송

- 자녀 기기의 Firebase 익명 사용자 UID
- 부모가 선택한 Google 계정의 Firebase UID, 이메일 주소와 표시 이름
- 자녀 기기 연결 식별자와 사용자가 정한 기기·프로필 이름
- 연결 코드, 연결 부모 UID와 연결 상태
- 차단 대상과 사유, 사용 시간·제한 시간
- 자녀 기기에서 앱별 현황 공유에 별도 동의한 경우, 오늘 많이 사용한 앱 최대 5개의 이름과 사용 시간. 전체 설치 앱 목록과 정확한 사용 시각은 이 현황용으로 전송하지 않음
- 부모가 사용 현황 새로고침을 누른 경우, 요청 식별자·부모 UID·요청/만료/완료 시각. 이 요청 문서에는 앱별 사용 기록을 저장하지 않음
- 추가 시간 요청, 승인·거절 결과와 처리 시각
- 원격 명령
- Firebase Cloud Messaging 토큰

### 오류 진단

사용자가 최초 안내에 동의한 뒤 앱 충돌과 응답 없음 문제를 개선하기 위해 Firebase Crashlytics가 충돌 시각, 기기 모델, OS 버전, 앱 버전, 스택 추적 등 진단 정보를 처리할 수 있습니다. Google Analytics는 사용하지 않습니다.

## 3. 이용 목적

- 앱별·그룹별·요일별 사용 시간 계산
- 차단 정책 적용과 블록 화면 표시
- 부모·자녀 기기 연결
- 추가 시간 요청과 승인·거절 알림
- 서비스 오류, 충돌 및 ANR 진단
- 보안 및 부정 사용 방지(App Check)

정보를 광고, 맞춤형 광고, 데이터 판매 또는 제3자 마케팅 목적으로 사용하지 않습니다.

## 4. 외부 처리 서비스

앱은 Google Firebase의 다음 기능을 사용합니다.

- Firebase Authentication
- Cloud Firestore
- Cloud Functions
- Firebase Cloud Messaging
- Firebase App Check / Play Integrity
- Firebase Crashlytics

각 서비스의 처리 위치와 보호조치는 Google/Firebase 약관 및 개인정보 관련 문서를 따릅니다.

## 5. 보관 기간

- 기기 내 사용 통계: 최근 30일 표시 및 정책 계산에 필요한 기간
- 추가 시간 요청과 원격 명령: 앱 정리 작업 기준 7일
- FCM 토큰: 같은 설치에서 갱신하며 연결 해제, 무효 토큰 확인 또는 계정 삭제 시까지
- 연결 코드: 새 코드 생성, 연결 해제 또는 정리 시까지
- 자녀·부모 연결 문서: 연결 해제 또는 삭제 요청 처리 시까지
- 자녀 사용 현황 요약: 자녀 기기별 현재 문서를 갱신하며, 앱별 공유 중지 후 재연결·동기화 시 앱별 목록을 비움
- 사용 현황 새로고침 요청: 자녀 기기별 현재 문서 하나를 갱신하며, 새 요청 시 이전 요청을 대체함
- Crashlytics 진단 정보: Firebase Crashlytics의 보관 정책에 따름

앱 내 계정·클라우드 연결 데이터 삭제 기능은 제공됩니다. 앱을 설치하지 않은 상태에서도 삭제를 요청할 수 있는 공개 HTTPS 페이지는 출시 전 게시해야 합니다.

## 6. 이용자의 선택과 권리

- 최초 모니터링 안내에 동의하지 않고 앱을 종료할 수 있습니다.
- Android 설정에서 사용정보 접근, 다른 앱 위 표시, 알림 권한을 철회할 수 있습니다. 권한 철회 시 차단 기능이 제한될 수 있습니다.
- 앱에서 부모·자녀 연결을 해제할 수 있습니다.
- 자녀 기기의 가족 탭에서 앱별 사용 현황 공유에 별도 동의하거나 공유를 중지할 수 있습니다. 오프라인에서 중지하면 서버의 이전 요약은 재연결·동기화 전까지 남을 수 있습니다.
- 계정 및 클라우드 데이터 삭제 요청: `설정 → 부모 관리 → 계정 및 클라우드 데이터 삭제`, 외부 URL `[게시 후 기재]`
- 개인정보 관련 문의: `[문의 이메일]`

## 7. 아동·청소년 정보

폰 쉼은 보호자가 자녀의 기기 사용 시간을 관리하는 기능을 제공합니다. 보호자는 관련 법령에 따라 필요한 설명과 동의를 제공해야 합니다. 대상 연령, 보호자 동의 절차와 Families 정책 적용 여부는 출시 국가 및 Play Console 설정에 맞춰 확정해야 합니다.

## 8. 보안

- Firebase 전송 구간 암호화
- Firestore 역할·필드별 최소 권한 규칙
- App Check Play Integrity
- 관리 PIN의 PBKDF2-HMAC-SHA256 해시 저장
- 반복 PIN 오류의 일시 잠금
- Firebase API 키의 Android 앱 제한

## 9. 변경

처리 항목이나 목적이 변경되면 앱 또는 공개 개인정보처리방침 페이지에서 시행 전에 알립니다.
