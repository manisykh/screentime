# 폰 쉼 출시 실기기 검증표

컴파일·설치와 장시간 검증은 사용자가 직접 수행합니다. 각 항목은 부모/자녀 역할, Android 버전, 제조사와 결과를 기록합니다.

결과 표기: `PASS`, `FAIL`, `BLOCKED`, `NOT TESTED`

## 1. 기본 설치와 권한

| 항목 | 기대 결과 | 결과/기기 |
|---|---|---|
| 신규 설치 | 모니터링 안내가 메인 화면보다 먼저 표시됨 | |
| 안내 거절 | 사용량 감시·FCM 토큰 등록·원격 동기화가 시작되지 않음 | |
| 안내 동의 | 단일 관리 PIN 최초 설정으로 이동 | |
| PIN 설정 | 4~8자리, 서로 다른 PIN만 허용 | |
| 사용정보 접근 거부 | 기능 제한 원인과 이동 경로가 명확히 표시됨 | |
| 오버레이 거부 | 블록 화면 제한과 복구 방법이 명확히 표시됨 | |
| 알림 거부 | 차단은 유지되고 부모 요청 알림 제한만 정확히 표시됨 | |
| 지속 알림 | `폰 쉼 · 사용 시간 관리 중`과 고유 아이콘이 계속 표시됨 | |

## 2. 프로세스와 전원 상태

| 항목 | 기대 결과 | 결과/기기 |
|---|---|---|
| 최근 앱에서 제거 | 감시가 복구되고 차단 정책이 유지됨 | |
| 강제 종료 후 직접 실행 | 상태와 오늘 사용량이 즉시 일관되게 복원됨 | |
| Doze 30분 이상 | 복귀 후 누락/중복 없이 사용량과 정책이 복구됨 | |
| 재부팅 | 동의·권한·정책이 유지되고 감시가 복구됨 | |
| 앱 업데이트 | 데이터와 연결이 유지되고 서비스가 복구됨 | |
| 화면 끄기 | 화면이 꺼진 시간은 앱 사용량에 포함되지 않음 | |
| 자정 통과 | 오늘 통계와 일일 제한이 한 번만 초기화됨 | |
| 시간대 변경 | 날짜별 통계가 중복되거나 사라지지 않음 | |

## 3. 다섯 가지 정책

| 항목 | 기대 결과 | 결과/기기 |
|---|---|---|
| 요일별 제한 | 해당 요일의 0분/제한 없음/시간 제한이 구분됨 | |
| 앱 그룹 제한 | 그룹 앱과 요일 예약이 정확히 적용됨 | |
| 앱별 제한 | 허용앱만 모드와 함께 사용해도 설정 시간이 지나면 차단됨 | |
| 스케줄 차단 | 스케줄 시작·종료와 허용 앱이 정확히 반영됨 | |
| 허용앱만 | 선택·제한 없음·시스템 자동·임시 허용 표시와 실제 결과가 일치함 | |
| 정책 중첩 | 적용 중인 시간 제한 중 가장 먼저 끝나는 조건에서 차단됨 | |
| 제한 없음 해제 | 즉시 정책 요약과 실제 차단 결과에서 제거됨 | |

## 4. 시스템 화면과 대표 앱 연동

| 항목 | 기대 결과 | 결과/기기 |
|---|---|---|
| 사진 선택기 | ChatGPT/메신저에서 사진 선택 시 차단되지 않음 | |
| Intent Resolver | 공유·앱 선택 화면이 차단되지 않음 | |
| 인쇄 | 갤러리에서 인쇄 선택 후 Print Service가 차단되지 않음 | |
| 전화/문자 | 대표 앱 설정과 관련 보조 앱의 허용 상태가 일치함 | |
| 카메라/갤러리 | 대표 앱과 시스템 보조 화면이 함께 정상 동작함 | |
| 키보드/설정 | 필수 시스템 화면은 차단되지 않음 | |

## 5. 블록 화면과 해제

| 항목 | 기대 결과 | 결과/기기 |
|---|---|---|
| 휴대폰 세로/가로 | 시스템 바 주변 빈틈 없이 자연스럽게 표시됨 | |
| 태블릿 세로/가로 | 하단 잘림 없이 전체 배경이 가려짐 | |
| 시간 추가 | 공통 Time Picker → 관리 PIN → 지정 시간 허용 | |
| 오늘만 허용 | 관리 PIN → 당일만 허용 | |
| 안전 복구 | 관리 PIN 팝업으로만 처리하며, 활성 고행 3단계에서는 Emergency Pass 안내 | |
| 부모 요청 버튼 | 연결된 자녀 기기에서만 표시됨 | |
| 홈/관리 앱 열기 | 화면 전환 직후 블록창이 비정상 재등장하지 않음 | |

## 6. 고행 모드

| 항목 | 기대 결과 | 결과/기기 |
|---|---|---|
| 1단계 숙고 | 앱별 카운트다운이 홈 이동 후에도 유지됨 | |
| 1단계 임시 허용 | 5분 뒤 다시 차단되고 종료 안내가 표시됨 | |
| 2단계 | 정의된 해제 제약을 우회할 수 없음 | |
| 3단계 | 다음 날 초기화 전 일반 PIN·설정 변경·모드 끄기로 해제 불가 | |
| 스케줄 3단계 | 해당 스케줄 종료 시 해제되고 아이콘/버튼 상태가 즉시 복구됨 | |
| Emergency Pass | 현재 앱 한정, 정책 자연 종료까지, 전체 3단계 공통 사용 후 7일 제한과 다음 사용 가능 시각이 일치함 | |

## 7. 부모·자녀와 FCM

| 항목 | 기대 결과 | 결과/기기 |
|---|---|---|
| 신규 연결 | 코드와 PIN 입력 후 두 기기에 동일 연결 상태 표시 | |
| 중복 요청 | 동일 자녀·대상은 최신 Pending 하나만 활성 | |
| 부모 프로세스 종료 | 자녀 요청 시 FCM 알림 도착 | |
| 승인/거절 | 자녀 프로세스 종료 상태에서도 결과가 반영됨 | |
| 다른 부모 기기 | 처리된 Pending 알림이 제거됨 | |
| 오프라인 요청 | 재시도 중 표시와 버튼 비활성화 후 연결 시 자동 완료 | |
| 연결 해제 | 이후 요청과 FCM이 해제된 부모에게 전달되지 않음 | |
| 무효 토큰 | 함수가 무효 토큰을 정리하고 나머지 기기에는 정상 전달 | |
