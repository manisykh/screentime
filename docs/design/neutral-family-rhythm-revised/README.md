# 폰 쉼 중립 시안 — 오늘·규칙 개정안

## 핵심 변경

- 스케줄을 사용하지 않는 상태를 기본 시나리오로 설계했다.
- `오늘` 탭은 고정 타임라인과 빈 스케줄 안내를 제거하고, 현재 적용되는 정책만 동적으로 노출한다.
- `규칙` 탭은 스케줄을 실행 범위의 선택 기능으로 유지하되 `사용 안 함` 상태가 자연스럽게 보이도록 했다.
- 시간 제한과 실행 범위를 분리하여 정책 결과를 쉽게 이해할 수 있게 했다.

## 화면

- `01-today-dynamic.png`: 스케줄이 없을 때의 오늘 탭
- `02-rules-optional-schedule.png`: 스케줄을 선택 기능으로 둔 규칙 탭

## 동적 노출 원칙

- 스케줄 0개: 오늘 탭에서 타임라인과 관련 안내를 표시하지 않는다.
- 활성 스케줄 1개: 전체 타임라인 대신 다음 변경 시각만 간결하게 표시한다.
- 활성 스케줄 2개 이상: 시간 흐름을 이해하는 데 필요할 때만 타임라인을 표시한다.
- 비활성 정책은 오늘 탭에 노출하지 않고 규칙 탭에서만 관리한다.

## 생성 방식

- 내장 이미지 생성 도구 사용
- 기준 해상도: Android 모바일 앱 콘텐츠 390 × 844
- 기존 `neutral-family-rhythm` 오늘·규칙 시안을 시각 기준으로 사용
- 중립적인 가족용 디자인, 따뜻한 미색 배경, 네이비 텍스트, 코발트·틸 상태색을 유지
