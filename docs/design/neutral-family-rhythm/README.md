# ScreenRest 중립형 Family Rhythm 시안

기준일: 2026-09-07

선택한 2번 시안의 하루 흐름과 친근한 여백을 유지하면서, 캐릭터·가족 초상·유아적 3D 일러스트를 제거한 연령 중립 디자인 세트다.

## 화면

1. `01-today.png` — 오늘: 현재 상태, 하루 흐름, 사용량, 요청, 오늘의 규칙
2. `02-rules.png` — 규칙: 현재 적용 결과, 시간 제한, 실행 범위
3. `03-statistics.png` — 통계: 7일/30일 추세, 목표 비교, 상위 앱
4. `04-family.png` — 가족: 자녀 선택, 승인 요청, 연결 기기
5. `05-more.png` — 더보기: 보호 상태, PIN, 긴급 사용권, 설정, 계정
6. `06-blocked.png` — 차단 화면: 차단 사유, 재사용 시각, 부모 요청과 복구 행동

## 공통 디자인 원칙

- 따뜻한 미색 배경과 짙은 남색 본문
- 파랑은 선택과 주요 행동, 청록은 정상 상태
- 주황은 요청·주의, 붉은색은 차단·위험 행동에만 사용
- 인물·캐릭터·장난감·침실 이미지를 사용하지 않음
- 아이콘은 동일한 굵기의 단순 선형 스타일
- 카드 안에 카드를 넣지 않고 여백과 구분선으로 그룹화
- 하단 탐색은 `오늘·규칙·통계·가족·더보기` 다섯 개로 통일
- 최소 48dp 터치 영역과 14~16sp 본문을 전제로 함

## 구현 시 주의

시안의 숫자와 상태는 레이아웃 설명용 예시다. 실제 앱에서는 기존 정책 엔진과 사용량 집계 결과를 그대로 표시해야 하며, 시안을 맞추기 위해 차단 우선순위·고행·PIN·Emergency Pass 로직을 변경하지 않는다.
